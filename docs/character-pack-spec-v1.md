# Character Pack Spec v1

Контракт контент-пака персонажа для роботов QAZBOT. Пак создаёт владелец робота (или QAZBOT), валидируется по `schemas/character-pack.schema.json` и раздаётся по флоту. Это наш формат — ядро платформы.

## 1. Роли

| Сторона | Ответственность |
|---|---|
| Мы (платформа) | Спека пака, валидатор, раздача по флоту, аудит показов, биллинг |
| Владелец робота / QAZBOT | Генерация персонажей в стандартных тулах, сборка паков по спеке |
| Робот (их AI-слой) | Голос (TTS), мимика на facial display, движение; читает пак и играет состояния |

Мы не трогаем управление роботом. Пак — только «что показать и когда».

## 2. Поверхности

- **facial_display** — встроенный экран робота (базовый слой, есть у каждого робота уже сейчас).
- **xr_glasses** — опциональный премиум-слой: AR-наложение для посетителей в смарт-очках.

Если пак заявляет поверхность, каждое состояние обязано иметь блок под неё (`facial` / `xr`) — проверяет валидатор.

## 3. Состояния и триггеры

Состояние входит по событию Genie Studio Agent — **только чтение**, пак ничего не пишет обратно в робота. Имена событий (`genie.idle`, `genie.visitor_detected`, …) — предварительные, до подтверждения каталога событий QAZBOT.

Минимальный набор: `idle` (цикл), `greeting`, `listening`, `speaking`. `fallback_state` — куда падать, если триггер без маппинга или ассет не загрузился.

## 4. Голос

Пак несёт **текст** реплик по локалям (`kk`, `ru`, `en`), синтез — их TTS. Аудио не храним: дешевле раздача, нет проблем с голосовыми правами.

## 5. Ассеты и целостность

Каждый ассет — в манифесте с `sha256`. Робот сверяет хеш при загрузке пака: подмена контента исключена. `pack://` URI резолвятся внутри раздаваемого пака; `file://` — проверяются валидатором локально.

## 6. Версионирование

`pack_version` — semver контента. Роботы тянут обновления по версии. `spec_version: v1` — валидатор отказывается работать с чужой версией спеки (тот же принцип, что `gestureDictionaryVersion` в XR-пресетах).

## 7. IP-чистота

`character.original_design: true` — аттестует, что дизайн оригинальный и не воспроизводит чужой IP (имена, внешность, силуэты). Пак с `false` к раздаче не допускается. Аудит показов (Defense-Dossier) с первого дня пишет «кто что видел и сколько раз» — это будущая база роялти-отчётности, когда пойдём за лицензиями.

## 8. Валидация

```
python3 tools/validate_character_pack.py examples/sample_character_pack.json --schema schemas/character-pack.schema.json
python3 tools/test_character_pack.py   # матрица позитивных/негативных проб
```

Проверяет: схему, уникальность id состояний, `fallback_state`, ссылки на ассеты, соответствие локалей, покрытие поверхностей, существование `file://` ассетов **и их целостность** (sha256 + bytes пересчитываются по файлу).

## 10. Честные ограничения v1

- **Референсный пак «Ару» — структурный пример.** Ассеты в нём — заглушки: `bytes: 0`, sha256 вычислены от строк-плейсхолдеров, реальных клипов и GLB в паке нет. `pack://` URI валидатором пропускаются — их целостность проверяется на стадии упаковки/раздачи, отдельной командой (пока не реализована).
- **Имена событий `genie.*` — предварительные.** Это не официальный API AgiBot: каталог событий Genie Studio Agent для партнёров ещё не подтверждён QAZBOT. Паттерн триггеров зафиксирован, имена — нет.
- **`original_design` — `const: true` в схеме.** Пак с `false` отклоняется на уровне схемы, а не только документацией.
